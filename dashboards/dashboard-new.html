Guia de Desenvolvimento & Docs

Estrutura do Endpoint

Os endpoints dinâmicos devem retornar um objeto JSON. Você tem acesso às variáveis query (parâmetros da URL) e fetch (para requisições externas).

// Exemplo de Estrutura Correta
const { cpf } = query;
if (!cpf) return { erro: "CPF obrigatório" };

const res = await fetch(`https://api.exemplo.com/v1/${cpf}`);
const data = await res.json();

return {
  sucesso: true,
  resultado: data
};

Padrões de Segurança

  • API_KEY: O sistema injeta automaticamente a validação de chave antes de chegar ao seu código.
  • WAF: Proteção contra SQL Injection e XSS é aplicada nos parâmetros da query.
  • Timeout: Requisições externas via fetch têm timeout padrão de 10s.
  • Retorno: Sempre retorne um objeto. O campo criador: "@MutanoX" é adicionado automaticamente.
DICA PRO:
Use try/catch dentro do seu código para capturar erros de APIs externas e retornar mensagens amigáveis.
